# CNN-building-components-detector-classifier

## Descripton

This project experiments with using synthetic data generated by an AR application with Convolutional Neural Network (CNN) and transfer learning to classify and detect real-world objects.

Tech stack: PyTorch, OpenCV, YOLO, Python

## how to install
1. Set up a virtual environment for Python
2. pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu132
3. pip install -r requirements.txt
