# CNN-building-components-detector-classifier

## Descripton

This is a project which makes use of synthetic data by a procedural building generator to train a CNN neural network, aiming to classify and detector some building components with the real world objects.

## how to install
1. Set up a virtual environment for Python
2. pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu132
3. pip install -r requirements.txt
